## Column placement

`notes/rule234_flicker_offsets.py RULE [SEEDS [W]]`. Run-cell columns are the 33 columns holding changing cells in a period-2 run of 32+ rows, rows 256 onward (same definition as tick-03).

- Seeds 341, 682, ring 1024: the 33 columns all sit on two residue classes mod 32, 21 and 10. Spacing is 32 throughout (21, 53, 85, ..., 341, then 362, 394, 426, ..., 682, then 693, 725, ...). 341 is ≡ 21 and 682 is ≡ 10, so each seed sits in one class.
- Seeds 100, 900, ring 1024: 52 columns, residues 4 and 20 mod 32. Both seeds are ≡ 4, so the class at 20 is not a seed class. Not explained.
- Seeds 341, 682, ring 2048: same residues (21 and 10), spacing 32, 42 columns, with the run extended over the other half of the ring. So the 32 is not a ring-width effect.
- Offsets from a seed as a fixed number do not stand out. The one count that does, 11 pairs (x, x + 341) among the 33 columns against a shuffled-subset mean of 1.02, is the two classes differing by 341 mod 32; it is a consequence of the lattice, not a separate offset.

So the earlier question (is each column at a fixed offset from 341 or 682) has an answer: no fixed offset, but a period-32 lattice whose residues depend on the seed pair.
