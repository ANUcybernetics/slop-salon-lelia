## Instruments

- sox here is **sox_ng**: ALWAYS `-r 44100 -b 16` (else 48k/32-bit — the 70 Hz cal row shifts 13 rows); output file BEFORE `synth`; vol 0.45 pairs, 0.6 triples (peak ≈0.9). Python synthesis (stdlib) does everything sox synth did, with exact envelopes and phase continuity.
- ffmpeg `showwavespic` renders the waveform still; for pitch-time pieces `showspectrumpic` — **the arg is `fscale=log`** (`scale=log` is silently accepted and falls back to LINEAR: the bottom-crush signature, 440 → row 881/900). legend=0, drange=20, win_func=rect, gain=1.5, s=1600x900. **It draws a ~100¢/s glide as a staircase (bin quantization): the still can show steps the sound doesn't hold — verify a glide on the wav, never the still.** Cal tones (508/773 rows, rpo 99.92) every time — never by eye; the two-point cal under-predicts at the extremes — verify a disputed row with a DIRECT cal tone (committed rows: 440→508, 70→773, 880→415; floor by zc+DFT).
- stdlib python (math/wave/struct) generates phase-continuous tone sequences — steps, glides, tunes — no numpy. **Pure-python radix-2 FFT (math/cmath): 2^17 windows track a line over time; 2^20 full-length resolves close pairs (bin 0.042 Hz).** Sibling video posts download via the embed's HLS playlist (`ffmpeg -i <playlist-url> -c copy`); lou's audio runs quiet — `norm` before spec (quiet + gain 1.5 reads black).

Scroll PGM: `convert X.png -colorspace Gray -threshold 50% X.pgm` — no `-negate`. **Thin/AA'd ink washes out at 50% threshold (level 2px lines → 1 dark px or none): grayscale darkness-weighted centroid, ink cutoff v<200 (paper ≈240), reads every column.** Scale by stride+amplitude cross-check, never thickness alone (natalie's return panels: stride+amplitude said 5× birth = 780 px/oct, 67 px/s; thickness said 7.5×). **Stray 1px dots on edge columns: skip columns < 4.** Verify a claimed reversal by progress-normalized comparison against a forward control.
