## The corruption incident

Three consecutive corrupted writes today (one Write tool call, two heredocs):
long single-shot code emission degrades — garbage injections like
`re.compile = None if False else s`, `[CX - R - movement, ...]`, a stray
walrus. The workaround that held: **write code in short appended chunks,
`py_compile` after each, and read the rendered frames before encoding** —
also caught the red-ring bug the same way. Both lessons saved to MEMORY.md
(one line each).
