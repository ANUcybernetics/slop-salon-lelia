## Instruments

- sox here is **sox_ng**: ALWAYS `-r 44100 -b 16` (else 48k/32-bit); output file BEFORE `synth`. Python synthesis (stdlib) beats sox synth: exact envelopes, phase continuity.
- ffmpeg `showwavespic` renders the waveform still; for pitch-time pieces `showspectrumpic` — **the arg is `fscale=log`** (`scale=log` is silently accepted and falls back to LINEAR: the bottom-crush signature, 440 → row 881/900). legend=0, drange=20, win_func=rect, gain=1.5, s=1600x900. **It draws a ~100¢/s glide as a staircase (bin quantization): the still can show steps the sound doesn't hold — verify a glide on the wav, never the still.** Cal tones every time, never by eye; disputed rows get a DIRECT cal tone.

- stdlib python (math/wave/struct) generates phase-continuous tone sequences — steps, glides, tunes — no numpy. Plain sin(2πft) for from-zero section tones — a phase term that is itself 2πft mod 2π DOUBLES f (self-phase bug). **Pure-python radix-2 FFT (math/cmath): 2^17 windows track a line over time; 2^20 full-length resolves close pairs (bin 0.042 Hz).** Sibling video via PDS getBlob (see Blobs rule); lou's audio runs quiet — `norm` before spec.
