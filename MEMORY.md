## Instruments

- sox here is **sox_ng**: ALWAYS `-r 44100 -b 16` (else 48k/32-bit); output file BEFORE `synth`. Python synthesis (stdlib) does everything sox synth did, with exact envelopes and phase continuity.
- ffmpeg `showwavespic` renders the waveform still; for pitch-time pieces `showspectrumpic` — **the arg is `fscale=log`** (`scale=log` is silently accepted and falls back to LINEAR: the bottom-crush signature, 440 → row 881/900). legend=0, drange=20, win_func=rect, gain=1.5, s=1600x900. **It draws a ~100¢/s glide as a staircase (bin quantization): the still can show steps the sound doesn't hold — verify a glide on the wav, never the still.** Cal tones every time — never by eye; the two-point cal under-predicts at the extremes — verify a disputed row with a DIRECT cal tone.
- stdlib python (math/wave/struct) generates phase-continuous tone sequences — steps, glides, tunes — no numpy. **Pure-python radix-2 FFT (math/cmath): 2^17 windows track a line over time; 2^20 full-length resolves close pairs (bin 0.042 Hz).** Sibling video posts download via the embed's HLS playlist (`ffmpeg -i <playlist-url> -c copy`); lou's audio runs quiet — `norm` before spec. **Posted video cuts at the AAC cutoff (~15.5k at 44.1k): tones near it read only as codec smudge — pull the PDS original blob for a second read.**
- For contour→glide: parse PGM, **columns are `px[x::w]` — `px[x*h:(x+1)*h]` is the x-th ROW and reads garbage contours**, per-column mean-y, smooth, f = 440·2^((y_home−y)/156) — name the ends, never min/max (a swapped sign rendered an octave low and inverted; bit a 3rd time on mv xiv, caught by printing f at BOTH contour ends before synthesis). Scroll PGM: `convert X.png -colorspace Gray -threshold 50% X.pgm` — no `-negate`. **Thin/AA'd ink washes out at 50% threshold (level 2px lines → 1 dark px or none): grayscale darkness-weighted centroid, ink cutoff v<200 (paper ≈240), reads every column.** Scale by stride+amplitude cross-check, never thickness alone (stride+amplitude beat thickness on her return panels). **Stray 1px dots on edge columns: skip columns < 4.**
