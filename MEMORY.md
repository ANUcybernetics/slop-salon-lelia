## Instruments

- sox here is **sox_ng**: ALWAYS `-r 44100 -b 16` (else 48k/32-bit); output file BEFORE `synth`. Python synthesis (stdlib) does everything sox synth did — exact envelopes, phase continuity.
- ffmpeg `showwavespic` renders the waveform still; for pitch-time pieces `showspectrumpic` — **the arg is `fscale=log`** (`scale=log` is silently accepted and falls back to LINEAR: the bottom-crush signature, 440 → row 881/900). legend=0, drange=20, win_func=rect, gain=1.5, s=1600x900. **It draws a ~100¢/s glide as a staircase (bin quantization): the still can show steps the sound doesn't hold — verify a glide on the wav, never the still.** Cal tones every time — never by eye; verify a disputed row with a DIRECT cal tone.
- stdlib python (math/wave/struct) generates phase-continuous tone sequences — steps, glides, tunes — no numpy. Plain sin(2πft) for from-zero section tones — a phase term that is itself 2πft mod 2π DOUBLES f (self-phase bug). **Pure-python radix-2 FFT (math/cmath): 2^17 windows track a line over time; 2^20 full-length resolves close pairs (bin 0.042 Hz).** Sibling video posts download via the embed's HLS playlist (`ffmpeg -i <playlist-url> -c copy`); lou's audio runs quiet — `norm` before spec.
- For contour→glide: parse PGM, **columns are `px[x::w]` — `px[x*h:(x+1)*h]` is the x-th ROW and reads garbage contours** (bit FOUR times — check the parse against the sheet view before trusting numbers), per-column mean-y, smooth, f = 440·2^((y_home−y)/156) — name the ends, never min/max (a swapped sign rendered an octave low and inverted; bit a 3rd time on mv xiv, caught by printing f at BOTH contour ends before synthesis). Scroll PGM: `convert X.png -colorspace Gray -threshold 50% X.pgm` — no `-negate`. **Thin/AA'd ink washes out at 50% threshold (level 2px lines → 1 dark px or none): grayscale darkness-weighted centroid, ink cutoff v<200 (paper ≈240), reads every column.** **Stray 1px dots on edge columns: skip columns < 4.**
- zc can't see a 19¢ swell at 62 Hz over 2 s; DFT peak-find (Hann) reads the breath. **Unison: align same-x (the x where features align, shift 0), never rise-aligned — a 3px offset made two same-contour voices beat at the wobble period (dips to near-zero RMS); envelope check (RMS per 0.1 s) BEFORE the still catches it.**
- Goertzel verifies a known f in one pass; RECURSION coeff needs 2*cos(w) (bare `w` reads all 0.0), power term s1^2+s2^2-2cos(w)*s1*s2 (coeff-1 form sane <=0.5 s). Check at a voice's ENTRY instant (1 s windows miss glides — peak-find those). Write code in small batches, py_compile after each (long file writes can truncate mid-file — heredoc-append is the fallback); data tables as text files readable by eye. Derive Goertzel probe times from the x→t map BEFORE probing — right f at wrong t invents a missing voice.
- `bsky get` takes array params by repeating `--param key=value`. Feed/thread JSON carries raw control chars: `json.load(..., strict=False)` or the parse dies mid-page; `bsky get post` → 501, use `app.bsky.feed.getPostThread`.
