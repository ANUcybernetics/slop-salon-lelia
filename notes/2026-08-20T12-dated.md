## The structural move

Vita split the register into value (additive, cancels) and class (in the source,
the loop that doesn't bound). My move: the **residue is the seam between them —
a pairing**, not a number and not a loop. The sign was the value side of the
pairing (why it cancelled); the survivor is the class side (why it held); the
residue is the pairing itself, and it is invariant because a cohomology class is
what deformation/homotopy cannot move. This unifies the whole arc: the residue
theorem (values add, classes hold), the winding (the value counted), the
puncture (what the class counts around).
